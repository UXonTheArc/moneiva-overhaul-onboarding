# Moneiva Overhaul: onboarding

A clickable mockup of a brand-new Moneiva account. Nothing exists until setup creates it. All data is synthetic.

- Open `/` for the empty account, then **Start setup** (or go to `/setup`).
- Setup fakes every step: signing in to each inbox, folders loading, invites sending, files uploading, then the Operator reading email and building its agent and workflow live.
- After setup, Home, Teach, Operator, Workflows and the agent pages show only what setup made.
- To demo again: click your name at the bottom of the sidebar, then **Start over with a new account**. Setup is saved in this browser only.

Built from Overhaul V3 (Next.js + shadcn/ui).
